# GoldenDrop Water Flow Meter Functions and Display Modes

## Display System

The GoldenDrop Water Flow Meter uses a digital display to provide water usage information.

---

# Four Display Modes

The product supports four main display modes:

1. FLOW RATE

2. LAST TIME

3. AVERAGE

4. TOTAL


---

# 1. FLOW RATE Mode

## Function

Displays the current water flow rate.

Long Press Function:

Switch measurement units.

## Purpose

Allows users to understand the current water flow passing through the meter.

Typical applications:

- Garden irrigation monitoring
- Hose water flow checking
- Outdoor water usage management


---

# 2. LAST TIME Mode

## Function

Displays the previous water usage amount.

Purpose:

Helps users review how much water was used during the previous watering activity.


---

# 3. AVERAGE Mode

## Function

Displays average water usage information.

Purpose:

Allows users to understand average consumption performance over recorded usage.


---

# 4. TOTAL Mode

## Function

Displays accumulated total water consumption.

Maximum Recorded Water Consumption:

99,999 Gallons


Purpose:

Helps users monitor total water usage during irrigation activities.


---
