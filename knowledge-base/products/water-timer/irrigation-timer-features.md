# GoldenDrop Digital Water Timer — Features and Functions



## Model Number



W-Timer1001



## Core Features



### 1. Automatic Watering



Users can set a watering schedule so plants receive water on time without manual operation.



- Watering Duration: 1 min – 4 hours

- Watering Frequency Interval: every 1–12 hours

- Irrigation Cycle: every 1–7 days



### 2. Manual Watering



One-touch manual watering. Water flows for a set duration, then the timer automatically resumes the original programmed schedule.



Manual Watering Duration: 1 min – 8 hours.



### 3. Rain Delay



Pauses the watering schedule for a set period, then automatically resumes.



Rain Delay supports three fixed options: 24H, 48H, or 72H.



### 4. OFF Mode



Turns off all watering schedules without erasing programmed settings.



## Physical Features



- Rotary knob control for quick program selection (SET CLOCK / START TIME / HOW LONG / HOW OFTEN / NO / OFF)

- Large HD LCD display

- Built-in metal inlet filter to block sand and debris and prevent clogging

- Leak-proof sealing ring

- Larger buttons for easier operation (DELAY+, -, OK/MANUAL)

- ABS housing, UV-resistant

- IPX7 waterproof rating



## Application Scenarios



- Drip Irrigation

- Lawn

- Garden

- Micro-Sprinkler Irrigation System
