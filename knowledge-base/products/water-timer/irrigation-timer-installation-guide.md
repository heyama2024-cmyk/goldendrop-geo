# GoldenDrop Digital Water Timer — Installation and Operation Guide



## Model Number



W-Timer1001



## Product Overview Components



- Filter

- Hose Tap Connection

- Large LCD Screen

- Dial (rotary knob)

- Buttons: OK/MANUAL, DELAY+, -

- Outlet



## 1. Installation



### 1.1 Install the Water Inlet Filter



The filter prevents impurities from entering and blocking the valve. Install the filter with the surrounding rubber ring in the connection to prevent leaks. Ensure the water inlet filter is installed correctly before use.



### 1.2 Install the Batteries



Requires 2 new 1.5V AA alkaline batteries (not included). Insert the batteries into the compartment, ensuring correct polarity. Close the compartment cover tightly to maintain waterproof integrity.



### 1.3 Install the Timer on the Faucet



Wrap Teflon tape around the faucet thread if needed to prevent leaks. Ensure the faucet outlet thread matches the timer inlet standard (NH or BSP). Hand-tighten the timer onto the faucet. Do not over-tighten.



### 1.4 Activate the Timer Valve Before Use



Turn the dial to ON. Press and hold the MANUAL button for 3–5 seconds to enter Manual Watering Mode and activate the valve before first use.



### 1.5 Check for Water Leaks Before Use



Stand clear of the water outlet to avoid splashing. Turn on the faucet slowly and check for leaks at the inlet connection.



## 2. Programming the Timer



### 2.1 Set Clock



1. Turn the dial to SET CLOCK.

2. Use the + or - button to select 12-hour or 24-hour format, then press OK to confirm. Use + or - to set the current time (select AM/PM if using 12-hour format).

3. Press OK to switch between hours and minutes.

4. Turn the dial clockwise to save and move to the next step.



### 2.2 Set Start Time



1. Turn the dial to START TIME.

2. Use + and - buttons to set the start time.

3. Press OK to switch between hours and minutes.

4. Turn the dial clockwise to save and move to the next step.



### 2.3 Set Watering Duration (How Long)



1. Turn the dial to HOW LONG.

2. Use + and - buttons to set the watering duration (minutes or hours).

3. Turn the dial clockwise to save and move to the next step.



### 2.4 Set Watering Frequency (How Often)



1. Turn the dial to HOW OFTEN.

2. Use + and - buttons to select the interval: every 1–12 hours, or every 1–7 days.

3. Turn the dial clockwise to save and move to the next step.



### 2.5 Automatic Watering



1. Turn the dial to AUTO.

2. The LCD screen displays the current time and the next scheduled start time.



## 3. Mode Introduction



### 3.1 Rain Delay Mode



Temporarily postpones watering for a set period without changing programmed settings.



1. Ensure the dial is in the ON position.

2. Press and hold the DELAY button for 3–5 seconds to enter Rain Delay mode.

3. Use + or - to select the delay period: 24H, 48H, or 72H.

4. Press OK to confirm. The screen shows a countdown of the remaining delay time.

5. To cancel Rain Delay, press and hold the DELAY button for 3–5 seconds to return to the previous schedule.



### 3.2 Manual Watering Mode



Allows immediate watering without interrupting the programmed schedule.



1. Turn the dial to ON.

2. Press and hold the MANUAL button for 3–5 seconds to enter Manual Watering Mode.

3. Use + or - to set a watering duration (1 min – 8 hours).

4. To stop manual watering, press and hold the MANUAL button for 3–5 seconds to return to the previous schedule.



### 3.3 OFF Mode



Turn the dial to OFF to stop all watering schedules without erasing programmed settings.



## 4. Operation and Maintenance



### 4.1 Battery Status



- Battery status is shown on the LCD screen.

- When the low battery indicator appears, the valve will automatically close to prevent leaks.

- Replace batteries promptly to restore normal operation.



### 4.2 Cleaning



Clean the water inlet filter periodically to prevent impurity buildup inside the timer.



## 5. Troubleshooting



| Issue | Possible Cause | Solution |

|---|---|---|

| Water leaks at valve | Filter not installed or misplaced / faucet not fully tightened / loose connections | Install filter correctly / tighten faucet connection / check connections |

| Water does not stop after set time | Normal short delay in valve closing / incorrect schedule / valve blockage | Wait a few seconds / check schedule settings / clean the valve |

| LCD display is blank or dim | Dead or low battery / incorrect battery polarity / cold temperature affecting display | Replace batteries / check polarity / display may recover in warmer temperatures |



## 6. Warnings



- Do not use the timer when water temperature is below 3°C (37.4°F) or above 50°C (122°F).

- Do not use tools to over-tighten the connection.

- If not used for a long period, remove the batteries and store the unit indoors.

- Do not attempt to disassemble or repair the unit. Contact customer service for support.
