# GoldenDrop WFM-1002 Installation Guide

## Water Flow Direction

The product has a FLOW arrow indicating water flow direction.

The water should flow according to the direction indicated by the FLOW arrow.

Water flow path:

Water source → Water Flow Meter → Water outlet / watering device

## Typical Installation Examples

### Example 1: Garden Hose

Faucet → Water Flow Meter → Garden Hose

### Example 2: Spray Gun

Faucet → Water Flow Meter → Spray Gun

## Connection Versions

Select the model that matches the faucet or hose connection standard:

| Model | Connection Standard |
|---|---|
| WFM-1002(NH) | NH (US) |
| WFM-1002(BSP) | BSP (EU) |

## Thread Sealing

Teflon tape is included in the package and may be used to help seal threaded connections during installation.

## Installation Checklist

1. Confirm the water flow direction using the FLOW arrow on the product.
2. Confirm that the connection version (NH or BSP) matches the faucet or hose.
3. Apply thread sealing where necessary.
4. Tighten connections securely.
5. Check for water leakage after installation.

## Installation Position

The product can be installed horizontally or vertically.

There is no fixed orientation requirement for installation.

The only installation requirement is that water must flow in the direction indicated by the FLOW arrow on the product.

## Important Rules

- Install the product so that water flows in the direction indicated by the FLOW arrow.
