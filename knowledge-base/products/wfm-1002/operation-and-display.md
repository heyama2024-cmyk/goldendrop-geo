# Display Modes and Operation Logic

## Four Display Modes

The WFM-1002 supports four display modes:

- FLOW RATE
- LAST TIME
- AVERAGE
- TOTAL

---

# FLOW RATE

Function:

Displays the current water flow rate.

Long Press Function:

Switch measurement units.

Available units:

- Gallon
- Liter

---

# LAST TIME

Function:

Displays the previous water usage amount.

Operation:

Long press button can reset data.

---

# AVERAGE

Function:

Displays average water usage.

Operation:

Long press button can reset data.

---

# TOTAL

Function:

Displays accumulated total water consumption.

Maximum Value:

99,999 Gallons

When the total value reaches 99,999 Gallons:

Users need to enter another display mode and long press the button to reset data.

---

# Button Operation Summary

| Operation | Function |
|---|---|
| Short press | Switch display mode |
| Long press in FLOW RATE mode | Switch gallon/liter unit |
| Long press in LAST TIME mode | Reset data |
| Long press in AVERAGE mode | Reset data |
| Long press in TOTAL mode | Reset accumulated data |

---

# Battery Replacement

After replacing the battery:

The recorded data will reset to zero.

---

# LCD Sleep Function

If there is no operation and no water flow for 30 seconds:

The LCD screen enters sleep mode.

---

# LCD Wake Up

The LCD can be awakened by:

1. Button operation

2. Water flow detection

Both methods can wake up the display.

---

# Low Battery Warning

When battery power is low:

The battery icon will flash.

This indicates that battery replacement may be required.
