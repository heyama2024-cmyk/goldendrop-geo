# Packaging Information

## Standard Package Contents

The package includes:

1. Water Flow Meter main unit
2. CR2032 button battery
3. Teflon tape
4. Cover opening tool
5. Screwdriver

---

## Battery Packaging

The CR2032 battery is included separately.

The battery is NOT pre-installed in the product.
